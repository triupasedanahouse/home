# TriUpasedanaHouse website

A responsive, static one-page website. It needs no server or database.

## Saved design versions

- `index-01-original.html` — the original warm guesthouse concept, with room carousels and general Bali imagery.
- `index-02-experience-odalan.html` — adds the Kenderan Experience, Odalan note and Kenderan gallery while retaining room carousels.
- `index-03-kenderan-researched.html` — the research-led version with Kenderan-specific copy and photos; this is also the current `index.html`.

Each saved page has its own matching stylesheet and script file, so editing one version will not change the others.

## Before publishing

- The site deliberately uses no generic room imagery. Add real, current TriUpasedanaHouse room photos only after you have selected and approved them.
- The Kenderan and property images are remote references from public tourism/property listings. Replace them with your own approved photos before the final launch if you would like to control the image rights and presentation.
- Check the exact amenities and room names against your current inventory.
- The WhatsApp button already uses **+62 852 3712 3025**.
- The Google Maps buttons use a search link for `TriupasedanaHouse`; replace it with the property's verified Maps share link after confirming it.

## Publish free with Netlify

1. Open [Netlify Drop](https://app.netlify.com/drop).
2. Drag the whole `site` folder into the page.
3. Netlify gives you a free public web address immediately.

You can later connect a custom domain through Netlify if you buy one.
